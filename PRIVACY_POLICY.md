# Privacy Policy — Sumrak VPN

**Application ID:** `com.sumrax.app`  
**Last updated:** November 2026

Sumrak VPN is a client for user-provided proxy/VPN configurations. It does not sell VPN access and does not operate its own VPN servers.

## Data we collect

- **On device:** server profiles, subscription URLs you add, app settings, and diagnostic logs you choose to view or share. Data is stored locally (MMKV and app storage) unless you export or back it up yourself.
- **Network:** the app connects only to servers and URLs you configure (subscriptions, updates, optional push via Firebase if enabled by the developer build).
- **Optional identifiers:** if Firebase Cloud Messaging is configured, Google may process an FCM device token to deliver push notifications. No account is required to use the app.

## Data we do not collect

We do not operate a central service that receives your browsing traffic. We do not require registration inside the app. We do not sell personal data.

## Permissions

The app requests permissions needed for VPN operation, notifications, camera (QR scan), optional install of APK updates, and per-app proxy (package visibility on some Android versions). Each is used only for the feature described in the in-app onboarding and system dialogs.

## Third parties

- **Upstream cores:** Xray/v2ray-compatible core (bundled library).
- **GitHub:** optional release checks using the public Releases API URL configured in settings.
- **Google Play / Firebase:** only if you install a build that includes Google Play services and Firebase configuration.

## Children

The app is not directed at children under 13.

Updates to this policy will be published in this repository.
