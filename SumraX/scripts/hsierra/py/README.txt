Sumrak VPN — Python GUI (macOS High Sierra)

Файлы:
  ../sumrax_gui.py          — окно с кнопками
  ../Sumrak VPN.command     — запуск GUI (двойной клик)
  check_python.command      — проверить python + tkinter

Запуск:
  1. Двойной клик «Sumrak VPN.command» (в корне папки)
  2. Первый раз: правый клик → Открыть
  3. Подключить

Без GUI:
  ../Start Sumrak VPN.command

config.json уже в ../config/config.json
